# Dashboard Plan

Recommended Tableau / Power BI layout for the final portfolio dashboard.

## Page 1 — Executive Overview

KPI cards:
- Total Service Requests
- Closed Request Rate
- Average Resolution Time
- Open / Pending Requests

Visuals:
- Monthly request trend
- Requests by borough
- Top complaint types
- Agency workload

## Page 2 — Service Performance

Visuals:
- Average resolution time by agency
- Average resolution time by complaint type
- Open-request backlog by agency
- Complaint volume vs. resolution time scatter plot

## Page 3 — Demand & Geography

Visuals:
- Requests by weekday and hour
- ZIP-code / coordinate hotspot map
- Borough and complaint-type filters

## Recommended Filters

- Borough
- Agency
- Complaint Type
- Month
- Status
- Open Data Channel Type

## Design Goal

The dashboard should answer three executive questions quickly:

1. Where is service demand coming from?
2. Which areas or categories are operationally slow?
3. Where should management prioritize resources?
